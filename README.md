## Lavio — AI Agent

# Lavio is a modern AI chat application built with Next.js, Prisma, and MongoDB, featuring secure authentication via Better Auth. It allows users to chat with an intelligent AI assistant powered by LangChain, with a sleek dark-themed interface and a scalable backend. In the future, Lavio will include RAG capabilities to interact with documents like PDFs, memory for context, web access, and real-time interactions, making it a full-featured AI agent.
